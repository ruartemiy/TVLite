1. Создайте новый репозиторий AppleTVLite на GitHub.
2. Распакуйте архив. Загрузите все файлы и папки из него в корень репозитория, включая скрытую папку .github.
3. Вкладка Actions -> Build Apple TV Lite APK -> Run workflow (либо сборка стартует после push в main).
4. После успешной сборки откройте запуск Actions и скачайте артефакт AppleTVLite-APK.
5. Распакуйте ZIP с артефактом. Внутри будет app-debug.apk. Скопируйте его на флешку.
6. Откройте APK на Android TV через файловый менеджер и разрешите установку из этого источника.
ВНИМАНИЕ: Это тестовая сборка. Не отключайте системный лаунчер Xiaomi до проверки.
